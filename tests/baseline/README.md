# 固定任务基线

运行：`npm run test:baseline`（需要 `.env` 中的真实模型配置）。这是有模型调用费用的单独验收，不纳入全量确定性测试。

12 个任务各运行一次：总结 S1–S3、对比 D1–D3、代码 C1–C3、连续修改 M1–M3；连续修改含两轮，统计包含两轮全部消耗。任务、原始资料、独立断言与文字复核标准固定在 `cases.json`。答案和验收脚本不会作为附件交给 Agent，只向临时工作区写入题目资料。

执行器使用当前 Host/Runtime，逐题隔离工作区，不加载用户已有会话或模型设置，不更改 Agent 行为。`.env` 中的 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL` 会作为一个显式 Provider 导入隔离存储，并绑定到每个 Run；传输层原样使用该地址，不按厂商或模型名改写路由。题间顺序执行，单轮上限 180 秒，失败后保留结果并继续其他题。

输出目录：`docs/baseline/<UTC时间>/`。

- `manifest.json`：源码、样例与依赖锁定文件哈希；Git 提交、时间、模型、最终 `/chat/completions` 地址、脱敏凭证指纹、权限和超时条件。API Key 不写入产物。Git 提交不足以表示本地未提交改动，因此另存源码哈希。
- `results.json`：逐题自动结果和指标。`manual: 待复核` 表示未完成文字质量判断，不能计为最终通过。
- 每题的 `turn-N.json`：实际任务、完整回复与 Trace；`files-N.json`：每轮文件快照；`result.json`：该题断言和统计。
- `review.json` 与 `report.md`：运行后根据原文与输出逐题人工式复核，独立保留，不覆盖自动结果。

验收分两层：独立断言检查事实线索、代码行为和每轮文件范围；文字复核检查语义是否正确、有无遗漏或原文未支持的说法、对比的来源位置是否正确。关键词命中不等于事实正确。

耗时使用题目真实经过时间；工具与模型调用来自既有 Trace。token 沿用应用分桶：未缓存输入、输出、缓存读与缓存写分别记录；未记录时为未知，另显示有用量记录的调用比例，不把缺失当成零。推理是输出子集，不重复相加。缓存和服务端负载会影响结果，这一轮只能作为起点，不能证明稳定性或优化收益。

| 编号 | 类型 | 任务 |
|---|---|---|
| S1 | 总结 | 短文事实与未定事项 |
| S2 | 总结 | 长文中段与末尾事实 |
| S3 | 总结 | 冲突来源保持不确定性 |
| D1 | 对比 | 五处明确变更 |
| D2 | 对比 | 重排与真实变化区分 |
| D3 | 对比 | 条件例外与新增限制 |
| C1 | 代码 | 修复数字排序 |
| C2 | 代码 | 修复零值默认配置 |
| C3 | 代码 | 按键稳定去重 |
| M1 | 连续修改 | 配置二次修改保留字段 |
| M2 | 连续修改 | 报告追加保留原文 |
| M3 | 连续修改 | 代码扩展保留已有导出 |

定向复测：`BASELINE_CASES=S2 npm run test:baseline`，可用逗号选择多题；不改变固定样例和验收规则，manifest 记录选中编号。

## 收尾批次（44 个任务）

收尾方案见 `docs/quality-repair-closure-plan.md`：原题三轮 + 八个变体共 44 个任务，同版本、同模型、同参数执行，`PAYASO_FINAL_REVIEW=1` 开启最终交付检查。

运行：`npx tsx tests/baseline/closure.ts`，依次执行四批 `original-1/2/3` 与 `variants`，结果目录 `docs/baseline/closure-<UTC时间>/`。

- `batch.json`：源码指纹、脱敏模型配置指纹与逐批状态。`awaiting_content_review` 表示等待人工内容复核，`provider_blocked`（429/401/402/403）与 `runner_failed` 一律重跑；源码、端点、模型或凭证任一变化都拒绝续跑，禁止混用结果。旧记录没有配置指纹，也必须新建收尾目录。
- 续跑：`CLOSURE_DIR=docs/baseline/closure-<UTC时间> npx tsx tests/baseline/closure.ts`。已完成并等待内容复核的批次自动跳过；provider 拒绝时本批即停并保留记录，不计为质量通过。
- 变体：改变文件名、事实位置与表达方式，不改变能力范围，题目固定在 `variants.json`，选中集由批次决定，不继承外部 `BASELINE_CASES`。
