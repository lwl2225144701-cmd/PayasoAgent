## 2. 验收原则

不能只断言“收到停止异常”。每条停止链路至少核查：

1. 停止前哪些请求或工具确实启动、完成。
2. 停止原因是预算、用户取消还是执行失败。
3. 请求尝试数与活动时长是否进入 checkpoint。
4. checkpoint 中实际保存的耗尽档位是否与停止原因一致。
5. 恢复后是否重新执行了本应被禁止的新工作。
6. 副作用是否重复发生，uncertain 是否保留。
7. Host 的内存、SQLite、SSE 和刷新后的展示是否一致。

统计口径：

- 模型调用次数按真实 Provider 请求尝试计量，包含内部重试、摘要和最终审查。
- 重复工具调用按模型发起的一次调用计数，内部执行重试另记 attempts。
- 一个工具回合是一轮模型响应中的全部工具处理结束，不能把多工具响应拆成多个回合。
- resume 延续同一个 Run 的预算；新的用户 Run 应拥有自己的预算，同时保留允许继承的摘要与历史。
- 实际 usage、未知 usage 和估算不得混成“真实用量为零”。
- 时间断言允许明确的调度容差；预算状态、调用数和副作用次数不允许用容差掩盖错误。

| SUMMARY-02 | 摘要中止后的保存 | 即使尚未发起主模型请求，也必须存在可恢复 checkpoint，并保存摘要耗时与耗尽档位。 |
| TOOL-01 | 同批三个工具跨限 | 第一个完成、第二个在途中止、第三个根本不启动；停止不记为普通执行失败。 |
| TOOL-02 | 工具超限后的保存 | checkpoint 包含工具阶段的累计时间，达到时间上限，耗尽桶包含 activeMs。 |

| CANCEL-02 | 用户取消工具 | 原因仍为用户取消；已消耗的工具时间保存，不因模型计数已经清零而漏账。 |
| NORMAL-01 | 正常长任务 | 15 个不同工作步骤正常结束；周期审查不硬阻断；原目标可见；不误报精确重复。 |
| WIRE-01 | JSON 兼容传输 | 一次 JSON 响应携带多个工具时，执行数量和顺序与 SSE 一致，不能合并或丢失调用。 |
| EFFECT-01 | 成功副作用恢复 | 在临时文件中真实写入一次；恢复重复调用只回放，不产生第二次写入。 |
| EFFECT-02 | uncertain 副作用恢复 | 工具实际写入后抛错；uncertain 被保存；恢复不能假定未执行而再写一次。 |
| ISOLATION-01 | 新用户 Run 隔离 | 保留上一轮摘要；不继承上一 Run 的耗尽预算；新任务可以执行自己的第一步。 |
| COMPAT-01 | 旧 checkpoint | 缺少新增治理字段仍可恢复；恢复后使用完整的新策略计量。 |
| HOST-01 | 预算停止的持久化 | stopped / budget_exhausted / partial 一致；SSE 只发布一个终态；SQLite 关闭重开后不变。 |
| HOST-02 | 耗尽后模型配合收尾 | 可完成回答，但交付仍为 partial；终态事件不能声称完全交付。 |
| HOST-03 | Host 主动取消 | stopped / user_cancelled / unknown 一致；不能遗漏取消原因或冒充预算耗尽。 |

### 核心回归的最小复现

配置累计活动时长 1000ms；一轮模型返回三个工具：650ms、650ms、立即完成。

- 第一个工具正常完成。
- 第二个工具在途越限后收到取消。
- 第三个工具启动次数必须为 0。
- 停止码必须为 budget_exhausted。
- 保存的累计活动时长必须达到 1000ms，耗尽桶必须含 activeMs。
- 从该 checkpoint 恢复，要求模型继续发起工具；启动次数不得增加。
- 任意一项不满足都不能通过验收，尤其不能只检查“已停止”。

## 5. 隔离和安全要求

- 默认只使用模拟模型，不读取真实 API Key，不请求真实 Provider。
- Runtime 用例只操作临时工作区；Host 用例使用临时 PAYASO_HOME、checkpoint 目录、SQLite 与内存 SecretStore。
- 验证副作用必须对真实临时文件或临时仓库做前后比较，不能只 mock fetch 后执行真实 Git 删除。
- Git 引用测试在独立临时仓库中进行，同时检查工作树和 refs；不能拿用户当前仓库作试验。
- SSE 测试持续推送实际片段，并记录取消是否抵达流；只延迟整包响应不能替代这项测试。
- 网络与进程分别隔离；原生进程测试只启动可识别的测试子进程，禁止全局杀进程。
- 每个场景恢复环境变量、模型替身、计时器、工作区选择和数据库连接。
- 完整失败记录保留场景编号、实际调用数、累计消耗、耗尽桶、停止原因及断点证据，不保存凭证或模型完整思考内容。
