# Host 任务约束接口

任务约束是 Host API/内部能力，不是普通 Web 输入功能。Web 界面只保留 Read Only、Workspace Write 和 Full access 这一个权限入口，避免把工作区权限、精确文件授权与内容摘录混成重复控件。

## 限定修改文件

例如 API 传入 `src/config.ts`：本轮内置文件工具只能修改这个文件，其他路径拒绝写入。Shell 对工作区只读，正式修改通过 write/edit 完成；沙箱私有临时目录仍可用于缓存。空数组表示禁止所有文件写入。

仅支持明确文件，不支持目录、通配符或软链接。新文件的父目录必须已存在。原来的权限设置仍有效，指定范围不会把只读任务升级为可写。

正文中的「只改某文件」仍是给模型的要求，不会被自然语言自动升级成文件授权。需要强制限制时，调用方必须传入结构化允许文件。

## 来源摘录（只读）

调用方传入来源文件及所问项目（例如「适用条件」「处理步骤」）。Host 在开始时固定文件版本；模型提交行号，Host 重新核对版本并提取原文，生成带来源的摘录表。

- 来源限 UTF-8 文本，每个不超过 1 MiB，最多 8 个文件、16 个所问项目。
- 无引用的项目显示「未找到证据」。引文相关性与完整性仍需评估。
- 引用格式错误、行号越界或文件变化，本轮失败，不发布未验证答复；当前不自动再调用模型重试。
- 此模式只提供摘录，不提供自由分析。普通总结仍可使用普通模式。

## API

创建 Run 的请求可附带以下任一 `constraints`，省略则保持普通任务行为：

```json
{"constraints":{"writeScope":["src/config.ts"]}}
```

```json
{"constraints":{"evidence":{"files":["docs/spec.md"],"items":["适用条件","处理步骤"]}}}
```

Host 校验并持久化授权与来源版本，Runtime 只传递写入范围，工具和沙箱负责执行限制。模型工具参数不能扩展授权。
